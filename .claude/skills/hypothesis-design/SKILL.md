# Design a hypothesis
1. State the mechanism and target population/domain.
2. Give a quantitative prediction and a clear observation that would falsify it.
3. Preregister commit and UTC observation-window start before collecting outcomes.
4. Identify data, controls, confounds, and minimum useful effect.
CLI: `hglab kb new hypothesis "TITLE"`.
Check: do not present post-hoc explanations as preregistered.
Example: predict a specified claim-delay difference for higher public rewards.
