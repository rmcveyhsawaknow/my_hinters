# Prove a claim
1. Label unsupported falsifiable ideas P0.
2. Cite public event IDs, tick ranges, or SHA-256 snapshots for P1.
3. Provide executable analysis and `hglab prove` result for P2.
4. Require independent role/runtime replication for P3; a preregistered successful forecast for P4.
Check: self-review never counts as P3; reserve “law” for cross-context P4.
Example: turn a descriptive event pattern into a script-backed P2 claim.
