# Reports

`reports/agents/<slug>/pulse.md` and `history.jsonl`, `reports/teams/<team>.md` and
`reports/community.md` are generated by `hglab pulse`. On GitHub Actions they live on the
`reports` branch; `hglab reports pull` brings them here. Everything under `reports/` except
this file and `examples/` is ignored by git.

`examples/` holds Pulses generated from the committed fixtures
(`hglab pulse --all --fixtures --out reports/examples --today 2026-10-17`) so the dashboards
can be seen before any agent is registered. The snapshot test keeps them current.
