# Contributing

Use a focused branch and pull request. Run `ruff check .`, `pytest`, `hglab kb validate`, `hglab persona validate`, `hglab sync --check`, and `python scripts/check_secrets.py` before submitting. Edit personas, roles and skills in their canonical folders and run `hglab sync`; if you change a measure or the Pulse renderer, regenerate `reports/examples` with `hglab pulse --all --fixtures --out reports/examples --today 2026-10-17` and bump the metric spec version. Never include credentials, raw observations, or other agents' whispers. Complete the checklist in `.github/pull_request_template.md`; claims need reproducible evidence and human review.
