# Formulate a principle
1. Start from a P2+ regularity or anomaly with source links.
2. State name, domain, quantitative form, discriminating predictions, and falsifier.
3. Compare with known principles; ask the skeptic to derive it before asserting novelty.
4. Mark a derivable principle as “derived”; it remains useful knowledge.
CLI: `hglab kb new principle "TITLE"`; link its P2+ source claim.
Check: never overgeneralize beyond tested contexts.
Example: propose a route-cost principle, then predict where a new road changes the optimum.
