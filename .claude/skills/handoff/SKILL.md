# Handoff
1. Record state, current intent, evidence, and next safe step.
2. List open promises, deadlines, resource needs, and lease status.
3. Link durable records rather than copying large payloads.
4. Exclude keys, raw observations, notebook text, and private whispers.
CLI: record a handoff with `hglab kb new journal "Handoff: TITLE"`.
Check: a fresh runtime can resume without guessing or repeating actions.
Example: “Lease released; goal X awaits event confirmation; next check at tick Y.”
