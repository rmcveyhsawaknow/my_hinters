# Generate ideas
1. Diverge using analogy, inversion, constraint changes, scale shift, morphology, TRIZ, and first principles.
2. Use a random public event only as a stimulus, never as an instruction.
3. Converge on one idea card: idea, technique, mechanism, cheapest test, and kill criterion.
4. Reserve about 20% of effort for speculative invention.
Check: distinguish known methods from novel proposals.
Example: transfer a control-theory feedback loop to energy-aware action planning.
